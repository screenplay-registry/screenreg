Verify a proof

Drop the original screenplay file, the .manifest.json envelope, and the .proof.ots proof. Verification runs entirely in your browser. Nothing is uploaded.

Privacy. This page is fully client-side; your script bytes never leave your browser. Open the Network tab in your dev tools and you will see no upload requests. When a proof references a Bitcoin block, this verifier reads the asserted block height and trusts the calendar's claim. For fully trustless verification, run the CLI against your own Bitcoin node.
